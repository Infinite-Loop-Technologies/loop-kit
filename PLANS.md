# Plans

This repo uses a simple GTD-style planning system.

- `docs/visions/`: strategic directions that can span multiple project plans and many next actions
- `docs/project-plans/`: big desired outcomes with support material and possible approaches
- `docs/next-actions/`: immediate executable actions that are still substantial enough for one focused session
- `docs/agent-inbox/`: captures, handoffs, and prompts that still need triage
- `docs/human-inbox/`: items blocked on a human
- `docs/ref/`: reusable references and workflow docs

Use the planning hierarchy as `vision -> project plan -> next action`.

`visions`, `project-plans`, and `next-actions` use the same status folders:

- `active`
- `wip`
- `on-hold`
- `someday-maybe`
- `completed`

If something takes only a few minutes, do it instead of recording it. Visions should stay strategic. Project plans should stay outcome-oriented. Exact next actions should move into `docs/next-actions/` quickly. For the full workflow, templates, and review habits, use [docs/ref/repo-workflow/index.md](./docs/ref/repo-workflow/index.md).
