# @loop-kit/tools

Bun-powered repo automation for Forge and loop-kit.

## Scripts

- `bun run forge-dev-plan`
- `bun run forge-dev`
- `bun run loopkit-oci-scaffold`
- `bun run workspace-audit`
- `bun test`
- `bun run typecheck`

Moon tracks this directory as the `tools` project and infers these scripts as tasks.
