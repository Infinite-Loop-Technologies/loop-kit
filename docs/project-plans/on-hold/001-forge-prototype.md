# Forge Prototype

Use ElectroBun with Bun. Use Moon for tasks of course.
Use the UI library.
Use InstantDB, and make sure to check with the docs [here](https://www.instantdb.com/llms.txt) at all times. Develop against a temporary app or a special development one using the [Platform API](https://www.instantdb.com/docs/platform-api).
