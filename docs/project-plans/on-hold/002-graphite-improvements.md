# Graphite Improvements

## Desired Outcome

Improve the set of Graphite packages, potentially introducing more. The packages are:

- packages/graphite
- packages/graphite-core
- packages/graphite-react
- packages/graphite-systems

Graphite is meant to have a very strong philosophy of favoring intent and previous intent, over just storing raw state. State is derived, like a view almost. This is inspired from [this article on intent](https://acko.net/blog/i-is-for-intent/).
