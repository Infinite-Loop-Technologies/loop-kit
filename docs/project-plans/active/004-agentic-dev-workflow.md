# Agentic Dev Workflow Foundation

## Desired Outcome

Establish a practical, controllable agentic development workflow for this repo using Dagger, Moon, MCP tools, and the GTD-inspired knowledge system so work can be executed asynchronously without degrading repo quality.

- Vision: [../../visions/active/001-agentic-development-workflow.md](../../visions/active/001-agentic-development-workflow.md)

- Validation guide: [../../ref/repo-workflow/validation-and-verification.md](../../ref/repo-workflow/validation-and-verification.md)

## Potential Steps

- Improve Moon task coverage and document useful task/query patterns for humans and agents.
- Make Moon MCP reliable in local agent sessions and verify its workspace-root configuration.
- Introduce Dagger as the short-term orchestration substrate for prompting, verification, and future event-driven runs.
- Build better knowledge-management helpers for inbox processing, next-action hygiene, stale-doc detection, and review rituals.
- Clean up glossary and terminology so the repo guidance matches the intended workflow.
