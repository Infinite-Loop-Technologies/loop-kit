# Initial Standard Surface Priorities

## Decision Needed

Confirm which parts of the standard surface should be first-class in the initial WIT package wave.

## Why It Matters

The package map should stay small, but the first slice still needs to unlock the host, registry, and automation story.

## Proposed Starting Position

Prioritize registry, runtime command execution, grants, workspace inspection, and automation worlds first. Push more specialized surfaces into extensions until the core is proven.

## Human Input Wanted

- Which surfaces feel unquestionably core to you?
- Which surfaces should stay out of core until later even if they are exciting?
