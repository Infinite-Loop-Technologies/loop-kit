# Weekly Review

Run this review to keep the repo fast to query and easy to resume.

## Checklist

1. Do a mind sweep and clear loose notes into `docs/agent-inbox/` or `docs/human-inbox/`.
2. Run an inbox emergency scan:
   process `docs/agent-inbox/`, do the small relevant items, and convert the rest into `docs/next-actions/...`, project plans, or visions.
3. Review `docs/next-actions/active` and `docs/next-actions/wip`:
   close stale actions, move blocked ones to `on-hold`, and make sure each still has a real project context and still deserves to be immediate.
4. Review `docs/project-plans/active` and `docs/project-plans/wip`:
   confirm each has a current next action or a clear reason it does not.
5. Review `docs/visions/active` and `docs/visions/wip`:
   confirm each still justifies its active status and still has the right project plans underneath it.
6. Scan `on-hold`, `someday-maybe`, and `completed` in visions, plans, and next actions for reactivation, outdated assumptions, or useful follow-up actions.
7. Scan `docs/ref/` for stale references and useful documents that should be linked from plans or next actions.
8. Review automation assumptions:
   check whether inbox injection, review dates, metadata helpers, Dagger functions, Moon queries, and MCP guidance still match reality.
9. If agents have been running autonomously for a while, do a deeper cleanup pass:
   process inbox residue, reconcile stale next actions, and make sure active projects still have live execution paths.
10. Check core guide docs such as `AGENTS.md`, `PLANS.md`, and `ARCHITECTURE.md` for stale paths if the repo structure changed.

The goal is not just cleanliness. The goal is to keep the next useful action obvious.
