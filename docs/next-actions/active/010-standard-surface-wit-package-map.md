# Standard Surface WIT Package Map

## Outcome

Define the first wave of loop-kit standard-surface WIT packages, interfaces, and worlds so the rewrite has a stable contract vocabulary to build against.

## Links

- Project plan: [../../project-plans/active/003-loop-refactor.md](../../project-plans/active/003-loop-refactor.md)

- Support material: [../../ref/loop-kit-fundamentals/index.md](../../ref/loop-kit-fundamentals/index.md)

## Next Actions

- Propose the minimum core package set and separate it from optional extensions.
- Define the first interfaces and worlds for registry access, runtime commands, grants, workspace inspection, and automation.
- Name the package families and establish directory conventions suitable for long-term growth.
- Record which worlds are expected to be implemented by components, default providers, adapters, or multiple runtime forms.

## Notes

- Keep the first surface deliberately small. A coherent v0 is more valuable than a prematurely exhaustive meta-platform.
