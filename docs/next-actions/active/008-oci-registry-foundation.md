# OCI Registry Foundation

## Outcome

Define the first registry product shape: canonical hosted registry, local cache model, artifact classes, auth expectations, and the high-level MCP-facing access story.

## Next Actions

- Decide the first remote registry baseline and document why it is sufficient for a v0.
- Define the artifact taxonomy that Loop cares about on top of OCI primitives.
- Define cache layout, digest rules, and offline/online behavior expectations.
- Define what the registry MCP surface should expose first and what should stay out of scope.

## Notes

- Keep the first version practical. The registry is foundational, but it does not need a speculative federation story on day one.
