# Next Actions

Next actions are the immediate execution surface of the repo. They should be large enough to spark real progress in a focused session, but not so large that they become a hidden project plan.

Use them for work that is clearly next, not merely someday useful.

- If something takes 2 minutes or less, do it now.
- If something takes roughly 5 minutes or less and it is obviously the right move, prefer doing it now instead of recording it.
- If the work is larger, create a next action with a clear outcome, links, and a short list of concrete moves.
