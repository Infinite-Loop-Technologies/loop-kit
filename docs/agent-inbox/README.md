# Agent Inbox

Drop new files here for agent-captured notes, prompts, handoffs, audit findings, bug reports, webhook payloads, and other future work. Markdown is the default, but other supporting artifacts are acceptable when they help the agent act later.

Process this inbox regularly:

- do 2-minute and 5-minute items now when they are clearly in scope
- run an emergency scan before pulling from active next actions
- convert larger work into visions, project plans, or next actions
- move human-blocked items into `docs/human-inbox/`
