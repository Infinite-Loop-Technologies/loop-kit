# Visions

Visions are the planning layer above project plans. Use them for repo-spanning strategic directions that may require multiple project plans and many next actions over time.

Use the planning hierarchy intentionally:

- `vision -> project plan -> next action`

Visions use the same status folders as other planning layers:

- `active`
- `wip`
- `on-hold`
- `someday-maybe`
- `completed`

Keep visions strategic. Put concrete large outcomes into linked project plans, and move exact next actions into `docs/next-actions/`.
