# @loop-kit/forge-contracts

Forge control-plane contracts, generated TypeScript types, and the generated fetch client SDK.

## Includes

- OpenAPI v0 REST contract
- AsyncAPI v0 realtime event contract
- Generated TypeScript types + SDK from OpenAPI
- Thin client runtime helpers for base URL and auth headers

## Local commands

- `pnpm --filter @loop-kit/forge-contracts validate`
- `pnpm --filter @loop-kit/forge-contracts build`
- `pnpm --filter @loop-kit/forge-contracts typecheck`
- `pnpm --filter @loop-kit/forge-contracts test`
